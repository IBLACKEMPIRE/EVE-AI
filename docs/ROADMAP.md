# Development milestones

1. **Audit:** verify reference repositories, licenses, build systems, APIs, maintenance and reuse strategy.
2. **Android shell:** launchable app with basic navigation, permissions and placeholder avatar.
3. **Conversation:** voice/text input, AI response, speech output and minimal secure memory.
4. **Avatar:** import custom rigged EVE model, animate face, lips, body and gestures.
5. **Background:** scheduled tasks, notifications, explicit approvals and activity history.
6. **Integration:** test performance, battery use, security, accessibility and APK packaging.

## Definition of done
Each milestone requires code, reproducible build instructions, tests and verified results. Do not claim APK functionality until an Android build succeeds.
